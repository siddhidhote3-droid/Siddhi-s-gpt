1️⃣ AI CHATGPT-LIKE ASSISTANT

🔹 Description

This project is an advanced AI assistant inspired by ChatGPT. It supports:

Text-based chat

Voice input & output

File reading (PDF / TXT)

Simple memory system

Web interface

Modular AI tools


This project is meant for learning how AI systems are structured, not for replacing real ChatGPT APIs.

🔹 Features

Web-based chat interface

Voice input using microphone

Text-to-speech replies

File reader AI (PDF/TXT)

Conversation memory (session-based)

Tool-based AI responses


🔹 Technologies Used

Python

Flask

SpeechRecognition

pyttsx3

Transformers / Rule-based AI

HTML, CSS, JavaScript


🔹 Folder Structure

chatgpt_ai/
│── app.py
│── ai_engine.py
│── memory.py
│── file_reader.py
│── voice.py
│── templates/
│   └── index.html
│── static/
│   ├── style.css
│   └── script.js
│── requirements.txt

🔹 How to Run

pip install -r requirements.txt
python app.py

Open browser and go to:

http://127.0.0.1:5000

🔹 Learning Outcome

How chatbots work

AI modular design

Voice + web integration

Memory handling in AI

3️⃣ AI FACE RECOGNITION SYSTEM

🔹 Description

This project is a real-time face recognition system that can:

Detect faces from camera

Recognize known people

Mark unknown faces


This project is widely used in security systems, attendance, and access control.

🔹 Features

Live camera face detection

Face recognition using encodings

Train new faces

Real-time bounding boxes


🔹 Technologies Used

Python

OpenCV

face_recognition library

NumPy


🔹 Folder Structure

face_recognition_ai/
│── train_faces.py
│── recognize_faces.py
│── faces/
│   ├── person1.jpg
│   └── person2.jpg
│── requirements.txt

🔹 How to Run

pip install -r requirements.txt
python train_faces.py
python recognize_faces.py

🔹 Learning Outcome

Computer Vision basics

Face detection vs recognition

Camera handling

AI security concepts
